# БЕЙТ — сайт восточной кофейни

Одностраничный сайт кофейни «БЕЙТ» в Самаре. Всё в одном файле `index.html` — HTML, CSS и JS вместе, фотографии встроены как base64, внешних зависимостей нет (кроме шрифтов Google Fonts).

## Разделы
- Hero с фото витрины и вывеской
- Ритуал кофе (иранский / марокканский / турецкий)
- Меню (5 вкладок: классика, авторские напитки, моктейли, лимонады, разное)
- История кофейни
- Галерея — слайдер с фото интерьера
- Контакты — адрес, часы, ссылки на карты (Яндекс/Google/2ГИС), WhatsApp, Instagram

## Публикация на GitHub Pages
1. Залейте этот репозиторий на GitHub.
2. В настройках репозитория откройте **Settings → Pages**.
3. В качестве источника выберите ветку `main` и папку `/ (root)`.
4. Через минуту сайт будет доступен по адресу вида `https://<ваш-логин>.github.io/<репозиторий>/`.

## Локальный просмотр
Просто откройте `index.html` в браузере — сервер не нужен.
